APPLE · IPHONE / IPAD

安装 iOS 描述文件

推荐 SAFARI
  1. 确认当前使用的是 Safari，点击下方按钮下载描述文件，并在弹窗中选择“允许”。
  2. 打开 设置 → 通用 → VPN 与设备管理，安装已下载的“上帝之眼 本地根证书”。
  3. 打开 设置 → 通用 → 关于本机 → 证书信任设置，为 God's Eye Local CA 打开完全信任。
  4. 回到 Safari，点击页面底部的“打开摄像机端”，确认地址栏的锁形图标正常。
安装 iOS 描述文件↓

描述文件不包含任何网络配置或隐私权限，只有一张本地根证书。可随时在“设置 → 通用 → VPN 与设备管理”中移除。

ANDROID · CHROME

安装 Android 证书

CA CERT
  1. 点击下方按钮下载证书文件 eye-of-god-ca.crt。
  2. 打开 设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书（不同品牌位置略有差异）。
  3. 选择刚下载的文件，确认安装。系统可能要求输入锁屏密码。
  4. 回到 Chrome，点击页面底部的“打开摄像机端”，首次连接应不再出现证书警告。
下载 Android 证书↓

部分 Android 系统会提示“您的网络可能受到监控”——这是安装本地 CA 的正常提示。这张证书只用于验证你自己的 Mac。

MACOS · 运行服务的这台 Mac

这台 Mac 也需要信任证书

管理端同样通过 HTTPS 与实时通道连接。首次使用时，请把证书加入“登录”钥匙串，并将“God's Eye Local CA”设为始终信任。Safari 和 Chrome 会自动使用系统钥匙串。

  1. 点击右侧按钮下载证书，双击打开“钥匙串访问”。
  2. 将证书添加到 “登录” 钥匙串，找到 God's Eye Local CA，双击打开。
  3. 展开“信任”，把“使用此证书时”设为 始终信任，关闭窗口并输入 Mac 密码。
  4. 重新打开管理端，确认地址栏锁形图标正常。
